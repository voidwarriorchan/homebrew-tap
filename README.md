# voidwarriorchan/tap

Homebrew formulae for voidwarriorchan's tools.

| Formula | Installs |
| --- | --- |
| `pike` | [pike](https://github.com/voidwarriorchan/pike), the Pi coding agent with a set of extensions built in, as one executable |

```sh
brew install voidwarriorchan/tap/pike
```

Use the full name. Homebrew's own `pike` is the Pike programming language, an
unrelated tool whose command has the same name. Since Homebrew 6, installing
by full name also trusts that one formula and nothing else in this tap.

`Formula/pike.rb` is generated for each pike release.
